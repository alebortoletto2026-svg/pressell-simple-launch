# Instruções para este repositório

## Branch de trabalho

Este projeto está conectado ao Lovable, e o Lovable só sincroniza com a branch
`main`. **Sempre desenvolva e publique (push) direto na `main`.** Não crie ou
use branches separadas para features — mudanças em qualquer outra branch não
aparecem no editor do Lovable nem no site publicado, mesmo que o push seja
bem-sucedido no GitHub.

Essa regra foi confirmada num projeto irmão do mesmo usuário
(a-jornada-voc-mais-mulher), onde um trabalho inteiro feito numa branch de
feature nunca apareceu no Lovable por esse exato motivo.
